# Libraries Hub (@intcloudsysops/*)

Librerías compartidas del monorepo Opsly.

## Librerías

- `api/` — API utilities (respuestas unificadas, versionado)
- `components/` — Componentes React compartidos (sistema de diseño)
- `config/` — Configuración de entorno y feature flags
- `content-studio/` — Generación de contenido editorial
- `errors/` — Manejo de errores con contexto
- `evaluation/` — Testing, validadores, QA gates
- `migrations/` — Versionado de migraciones DB
- `observability/` — Logging, métricas, tracing unificados
- `prompts/` — Registry de prompts versionados
- `runtime/` — Environment detector, executor local
- `security/` — Autenticación, cifrado, redacción PII
- `services/` — Patrón Repository con aislamiento multi-tenant
- `session-manager/` — Gestión de sesiones de agente
- `telemetry/` — Costo y rendimiento por agente
- `testing/` — Framework de tests unificado
- `workflow/` — Ejecución segura de agentes con timeouts y costos

Otras: `external-agent-registry/`, `git-branch-orchestrator/`, `repo-governance/`
