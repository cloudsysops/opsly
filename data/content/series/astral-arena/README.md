# Astral Arena Content Series

This directory is the **editorial production representation** of Astral Arena Season 1.

It is not the canonical lore database.

Sources of truth:

- canon/characters/worlds → `@intcloudsysops/universe`;
- missions/rules → `@intcloudsysops/game-core`;
- mission↔episode mapping → `config/games/astral-arena-transmedia.json`;
- editorial scripts/storyboards → this directory;
- rendered clips/media state → Content OS v2 envelopes;
- approval → Moon Creator Studio.

## First production batch

- S01E01 — The Sisters Awaken
- S01E02 — Orion, Guardian of Earth
- S01E03 — Aurora Chooses
- S01E04 — NX-7 Wakes Up

Episodes 5–16 now exist as **idea-stage editorial slots** with no authored scenes.
They reserve production identity without inventing canon before their game missions mature.

## Rule

A content episode can dramatize or explain a canonical event, but cannot silently
change the event. Canon changes must happen in Universe first and then propagate.
