# OPSLY Universe Saga Config

Machine-readable canon for the OPSLY / ICSO story system.

Files:

- `characters.json` — main cast and brand IP roles
- `worlds.json` — MUNDUS, NEXUS, AETHER, tenant planets
- `symbols.json` — geometric and numeric language
- `episode-templates.json` — reusable episode structures
- `ideas.json` — first launch package for stories and videos
- `campaigns.json` — campaign plan, mix, and approval rules
- `briefs.json` — detailed brief, script, storyboard, and derivatives

Rules:

- Keep tenant branding separate.
- Use the story bible as the human-readable source of truth.
- Extend by tenant fixture, not by hardcoding Peskids into core.
