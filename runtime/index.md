# Runtime Hub

Estado de ejecución, contexto operativo y datos dinámicos de Opsly.

## Directorios

- `context/` — Estado del sistema (system_state.json)
- `letsencrypt/` — Certificados ACME
- `logs/` — Logs de ejecución
- `pids/` — PID files de servicios
- `tenants/` — Datos de tenants activos
