# Cursor Configuration Hub

Configuración, reglas, prompts y respuestas del agente Cursor para Opsly.

## Subdirectorios

- `goals/` — metas de sesión
- `hooks/` — hooks de sesión
- `prompts/` — prompts operativos
- `responses/` — respuestas registradas
- `rules/` — reglas Cursor (.mdc)
- `.validation/` — validaciones de estructura
