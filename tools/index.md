# Tools Hub

Herramientas auxiliares, scripts CLI y utilidades operativas de Opsly.

## Herramientas

- `agent-packs/` — Paquetes de agentes
- `agents/` — Scripts de agentes
- `cli/` — CLI tools (docker_provisioner, etc.)
- `live-automation/` — Automatización en vivo
- `productivity-starter/` — Kits de productividad
- `usb-kit/` — Kit USB de rescate (pendrive)
- `workspaces/` — Gestión de workspaces
