# Applications Hub

Aplicaciones del monorepo Opsly — APIs, frontends, servicios y workers.

## Apps principales

- `api/` — Control plane API (Next.js)
- `admin/` — Dashboard admin (Next.js)
- `portal/` — Portal de cliente (Next.js)
- `orchestrator/` — Orquestador BullMQ
- `llm-gateway/` — LLM Gateway con routing y costos
- `mcp/` — MCP server (herramientas)
- `peskids/` — Plataforma Peskids (Next.js)
- `context-builder/` — Pipeline de contexto
- `ml/` — ML services (clasificación, embeddings)
- `notebooklm-agent/` — NotebookLM integration
- `billing-service/` — Facturación Stripe
- `billing-dashboard/` — UI de facturación
- `local-services/` — Servicios locales

Otras: `airflow/`, `agent-manager/`, `agents/`, `mcp-gateway/`, `mcp-rendering-server/`, `notion-mcp/`, `slack-bot/`, `tenant-invitations/`, `tenant-onboarding-agent/`, `experimental/`
