# Operations MOC

Validación operativa, estado de operación y guías no procedimentales.

## Qué va aquí

- Guías de operación que explican criterios y validaciones.
- Material operativo que no es un runbook paso a paso.

## Qué no va aquí

- Procedimientos accionables; usar `../runbooks/`.
- Reportes de una sesión puntual; usar `../reports/`.
