# GAME VISION

Opsly Universe can power a game later, but the game must inherit the canon rather than replace it.

First playable slice:

- Explorer wakes up in the Nexus.
- Traveler provides the first threshold.
- One world opens.
- One Bit or companion is encountered.
- One challenge is solved.
- One fragment of the map is earned.

The game should teach exploration, cooperation, building, safety, and curiosity through play.
