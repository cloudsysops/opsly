# ADRs — Architecture Decision Records

Decisiones de arquitectura numeradas. Convención: un ID por decisión; suplementos en subcarpetas (p. ej. `ADR-043-supplement/`) sin duplicar el número principal.

## Enlaces

- Política de docs: [`../STRUCTURE-GUARDRAILS.md`](../STRUCTURE-GUARDRAILS.md)
- Índice Obsidian: [`../index.md`](../index.md)
- Archivos en esta carpeta: prefijo `ADR-NNN-*.md`

## Cómo añadir un ADR

1. Elegir el siguiente número libre.
2. Crear `docs/adr/ADR-NNN-titulo-kebab.md` con contexto, decisión y consecuencias.
3. Enlazar desde docs relacionadas (orquestación, infra, agentes).
