# Splashitos — subir YA (natación kids → oferta Peskids)

Canal ICSO propio. **Sin marca Peskids** hasta contrato.

## Carpeta kit

`runtime/content-studio/youtube-upload-kit/splashitos/`

MP4 + `.txt` (título/descripción) + `manifest.json`.

## En tu Chrome Studio (2ª pantalla)

1. **Crear canal** (si falta): nombre **Splashitos** bajo IntCloudSysOps Open.
2. Crear → Subir videos → arrastra los MP4 del kit.
3. Copia título/descripción de cada `.txt`.
4. Audiencia: **No hecho para niños** (padres que enseñan) salvo que el video hable solo al niño.
5. Visibilidad: **Oculto** → revisas → **Público**.

## Por qué esto genera plata

1. Ahora: audiencia + Partner en canal ICSO.
2. Después: **vender el pack/cadencia a Peskids** (Starter / Co-brand / White-label).  
   Detalle: [`YOUTUBE-KIDS-SWIM-CHANNEL.md`](./YOUTUBE-KIDS-SWIM-CHANNEL.md).

## Comandos

```bash
npm run content:splashitos:dry-run
npm run content:splashitos:publish -- --kit
```
