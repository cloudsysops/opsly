# ICSO Agency Setup

1. Open agency profile and set `IntCloudSysOps`.
2. Set short name `ICSO`.
3. Apply brand colors and typography.
4. Upload logo and favicon.
5. Configure email branding.
6. Create roles.
7. Check domains and whitelabel.
8. Prepare snapshot placeholders.
9. Rename dashboard sections.
10. Validate settings.
