# Claude Chrome Operating Rules

- Never change billing.
- Never delete existing workflows.
- Never modify production webhooks without confirmation.
- Never overwrite Peskids live settings without approval.
- Always screenshot before and after.
- Always ask before saving destructive changes.
- Work one screen at a time.
- Report blocker immediately.
