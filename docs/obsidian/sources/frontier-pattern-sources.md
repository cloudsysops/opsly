## What this source set covers

This source set is a curated GitHub reading list for pattern mining across
space, navigation, marketing, architecture, and temporal systems. It is used to
extract reusable software patterns, not to copy product UI or domain jargon.

## Claims

- Space and satellite projects emphasize simulation, telemetry, and ground-control loops.
- Navigation projects emphasize geospatial state, route planning, and sensor fusion.
- Marketing platforms emphasize activation, retention, experimentation, and replay.
- Architecture catalogs emphasize event lineage, service boundaries, and flow visibility.
- Temporal/debugging tools emphasize replay, snapshots, and time-aware inspection.
