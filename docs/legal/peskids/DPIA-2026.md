> **Nota:** Los datos de menores (P0) activan los requisitos del art. 7 Ley 1581 y Decreto 1377 art. 12.

### 1.3 Flujo de datos

```
Acudiente
   │ formulario web (lead-capture-form.tsx)
   ▼
API Peskids (/api/leads)
   ├── Supabase (tabla peskids_leads) ── Colombia / USA* 
   ├── Jelou (mensaje WhatsApp) ──────── Ecuador / Colombia
   └── n8n @ peskids.op-sly.com ─────── Colombia (VPS Opsly)
         └── Notificación interna

Asistente IA (peskids-chat-panel)
   │ conversaciones
   ▼
API Peskids (/api/chat)
   └── Anthropic Claude API ──────────── USA
         └── No retención por defecto (sin API caching de prompts activado)

* Supabase es gestionado por Supabase Inc. (USA). DPA: https://supabase.com/legal/dpa
```

> **Transferencia internacional:** USA no está en la lista de países adecuados de la SIC.  
> Legitimación: autorización expresa del titular conforme al art. 26 Ley 1581 — el acudiente  
> es informado antes de otorgar el consentimiento (aviso parental + checkbox de tratamiento).

## 2. Necesidad y Proporcionalidad

### 2.1 Minimización de datos

| Campo | ¿Necesario? | Acción recomendada |
|-------|-------------|-------------------|
| Nombre del acudiente | Sí | Mantener |
| Email | Sí | Mantener |
| Teléfono/WhatsApp | Sí (canal principal) | Mantener |
| Barrio/sector | Parcialmente | ⚠️ Evaluar si es necesario o puede ser opcional |
| Nombre del menor | No en etapa de lead | ✅ No solicitar hasta confirmación de matrícula |
| Rango de edad | Sí (nivel de clase) | Mantener solo el rango, no fecha de nacimiento |

**Decisión adoptada (2026-05):** El nombre del menor NO se recolecta en el formulario de lead. Solo se solicita el rango de edad. El nombre se obtiene en el contrato de matrícula.

### 2.2 Retención

| Dato | TTL | Acción al vencer |
|------|-----|-----------------|
| Leads no convertidos | 730 días (2 años) | Borrado automático (governance.retention_schedule) |
| Leads convertidos (estudiantes activos) | Vigencia del servicio + 5 años | Anonimización o borrado |
| Logs de conversaciones IA | 90 días | Borrado automático |
| Audit logs | 730 días | Borrado automático |
| Consentimientos registrados | 5 años | Archivo (evidencia legal) |
| Datos de facturación | 10 años | Cumplimiento tributario colombiano |

## 3. Identificación y Gestión de Riesgos

### 3.1 Mapa de riesgos

| # | Riesgo | Probabilidad | Impacto | Nivel | Medida de mitigación |
|---|--------|-------------|---------|-------|---------------------|
| R1 | Acceso no autorizado a datos de menores | Baja | Crítico | **Alto** | RLS Supabase, JWT auth, service_role only |
| R2 | Fuga de datos a Jelou sin consentimiento | Media → Baja | Alto | Medio | Disclosure explícito en checkbox, DPA con Jelou pendiente |
| R3 | Conversaciones IA usadas para entrenamiento de modelos | Media | Medio | Medio | API Anthropic: no retención por defecto; verificar en DPA |
| R4 | Fuga de base de datos por mala configuración RLS | Baja | Crítico | **Alto** | Migraciones revisadas; audit trail habilitado |
| R5 | Incumplimiento del TTSL de DSAR (15 días) | Media | Alto | Medio | governance.dsar_requests con sla_deadline automático |
| R6 | Exposición de datos en logs de n8n | Media | Medio | Medio | n8n self-hosted; logs en VPS Opsly (acceso restringido) |
| R7 | Ausencia de DPA firmado con sub-procesadores | Media | Alto | Medio | Ver acción R2; priorizar Jelou y Anthropic |

### 3.2 Controles implementados

- ✅ **Consentimiento parental registrado** en `governance.consents` con versión de política, IP y timestamp
- ✅ **Aviso de autorización parental** conforme a Decreto 1377 art. 12 (página `/aviso-parental`)
- ✅ **Política de privacidad** con sección específica de menores y canales SIC
- ✅ **Cookie banner** con bloqueo de recursos de terceros hasta consentimiento
- ✅ **Disclosure de IA** en panel de chat con consentimiento previo
- ✅ **DSAR page** (`/dsar`) + endpoint backend con SLA 15 días hábiles
- ✅ **Retention cron** configurado para borrado a los 730 días
- ⚠️ **DPA con Jelou** — pendiente firma
- ⚠️ **DPA con Anthropic** — verificar cláusulas de entrenamiento con datos de menores
- ❌ **Penetration test** — programar antes de escalar a 100+ usuarios
