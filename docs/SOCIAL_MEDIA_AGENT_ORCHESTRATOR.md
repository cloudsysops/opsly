                    ## 2. COPILOT AGENT SPECIFICATIONS

                    ### 2.1 Agent: `social-media-orchestrator`

                    **Purpose:** Autonomous content generation, scheduling, and distribution across all channels

                    **Capabilities:**

                    ```yaml
                    Agent: social-media-orchestrator
                    Role: Multi-Channel Content Automation AI
                    Responsibilities:
                      - content_generation: Daily AI-written posts, captions, hashtags
                        - video_production: Script generation, thumbnail design, editing
                          - image_creation: AI graphics, branded assets, infographics
                            - scheduling: Auto-post at optimal times per timezone
                              - analytics: Engagement tracking, ROI per vertical
                                - moderation: Comment monitoring, spam filtering, QA
                                  - optimization: A/B test variations, trend analysis
                                    - translation: Multi-language content (EN/ES primary)
                                      - meta_integration: Native Facebook/Instagram/YouTube APIs

                                        Execution Frequency:
                                          - Primary: Daily at 00:00 UTC (generates 24h content)
                                            - Secondary: Every 4 hours (real-time trending responses)
                                              - Emergency: On-demand via /copilot slash command
                                              ```
