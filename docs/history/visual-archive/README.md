## Curation policy

2. Keep date and source title in metadata/index.
3. Deduplicate exact copies; retain meaningful design variants.
4. Create publication-safe filenames.
5. Do not overwrite historical snapshots.
6. Prefer PNG/WebP/AVIF derivatives for web publishing while keeping one original-quality source.
7. Link visuals to the relevant product/architecture issue or epic when known.
