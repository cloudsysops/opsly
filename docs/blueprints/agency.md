# Agency Blueprint

## Objetivo

Replicar el modelo Opsly para una agencia partner que vende y opera clientes sin ver el stack interno.

## Flujo base

Lead entra → agencia vende → Opsly opera → cliente recibe resultados → dashboard muestra avance.

## Componentes

- Oferta comercial
- Pipeline de ventas
- Dashboards por cliente
- Automatización
- Handoff operativo
- SOPs de onboarding y soporte

## KPIs

- Leads nuevos
- Calls agendadas
- Clientes cerrados
- Retención
- Clientes activos
