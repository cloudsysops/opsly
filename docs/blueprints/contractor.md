# Contractor Blueprint

## Objetivo

Operar servicios para contractors con un flujo comercial simple y repetible.

## Flujo base

Lead entra → se agenda visita → se envía propuesta → se cierra → se entrega el trabajo → se pide reseña.

## Componentes

- Pipeline de cotización
- Formularios de contacto y tipo de proyecto
- Landing de captación
- Seguimiento comercial
- Dashboard ejecutivo
- Onboarding del equipo

## KPIs

- Leads nuevos
- Visitas agendadas
- Propuestas enviadas
- Cierres
- Revenue
