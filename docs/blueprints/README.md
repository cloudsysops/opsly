# Blueprints

Context entrypoints por vertical. Estos archivos son la capa compacta para sesiones de agente; los detalles extensos viven en `opsly-operational-blueprint/` y en los docs de tenant.

| Archivo | Cuándo usarlo |
| --- | --- |
| [`academy.md`](academy.md) | Academias: pipeline, formularios, seguimiento, dashboard y onboarding. |
| [`academy-ghl-import.md`](academy-ghl-import.md) | Paquete operativo listo para exportar/importar en GHL. |
| [`academy-commercial-package.md`](academy-commercial-package.md) | Oferta comercial, pricing, scripts y proposal template para vender Academy. |
| [`academy-commercial-one-pager.md`](academy-commercial-one-pager.md) | Resumen compacto para exportar a PDF y usar en ventas. |
| [`contractor.md`](contractor.md) | Contractors: cotización, visita, propuesta, cierre y seguimiento. |
| [`agency.md`](agency.md) | Agencia: partners, operación comercial y replicación del modelo. |
| [`dental.md`](dental.md) | Dental: captación, cita, tratamiento y recall. |

Regla: carga solo el blueprint que corresponda al tenant o sesión activa.
