# Dental Blueprint

## Objetivo

Operar una clínica dental con captación, seguimiento y recall sin montar un CRM nuevo.

## Flujo base

Lead entra → se agenda consulta → se evalúa → se propone tratamiento → se cierra → se hace seguimiento y recall.

## Componentes

- Pipeline de pacientes
- Formularios de captación
- Landing
- Workflows
- Dashboard
- Onboarding del equipo

## KPIs

- Leads nuevos
- Citas agendadas
- Evaluaciones
- Tratamientos cerrados
- Recall / reactivación
