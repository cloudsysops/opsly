# ICSO Academy Commercial Package

**Source blueprint:** [Academy Growth Blueprint V1](./academy.md)  
**Operational companion:** [Academy Growth Blueprint - GHL Import Package](./academy-ghl-import.md)

## Purpose

Convert the Academy Blueprint into a commercial offer that can be sold, implemented, and repeated across academies, schools, courses, trainers, and education centers.

This package does **not** redesign the business model. It packages the existing operating system into clear offers, scope boundaries, and sales assets.

## Package Ladder

### 1) Starter Package

**Best for:** small academies that need lead capture and follow-up working fast.

| Item | Value |
|---|---|
| Setup fee | `$950` |
| Monthly fee | `$149/mo` |
| Implementation time | `3-5 business days` |
| ROI expected | `Faster response time, fewer missed leads, basic trial booking consistency` |

**Includes**

- Academy Growth Pipeline
- Free Trial Form
- Core tags
- Core custom fields
- 1 lead intake workflow
- 1 trial reminder workflow
- Welcome email and SMS
- Basic dashboard mapping
- One simple team notification flow

**Does not include**

- Custom dashboard design
- Advanced segmentation
- Multiple calendars
- Multi-branch reporting
- Migration or extraction work
- Ongoing optimization beyond the basic monthly scope

### 2) Growth Package

**Best for:** academies that already have leads coming in and need better conversion control.

| Item | Value |
|---|---|
| Setup fee | `$2,500` |
| Monthly fee | `$399/mo` |
| Implementation time | `1-2 weeks` |
| ROI expected | `Higher trial-to-enrollment conversion, better operational visibility, less manual follow-up` |

**Includes**

- Everything in Starter
- Full Academy Growth Pipeline
- All academy tags
- Full custom field set
- Post trial follow-up workflow
- Enrollment success workflow
- 4 email templates
- 4 SMS templates
- Dashboard widgets for leads, trials, enrollments, active students, revenue
- Source tracking and lead source breakdown
- Priority onboarding and handoff

**Does not include**

- Custom reporting app
- Complex integrations outside GHL
- White-label extraction
- Bespoke automation engineering beyond the blueprint

### 3) Pro Package

**Best for:** larger academies, partner brands, or multi-program operations that want a more complete system.

| Item | Value |
|---|---|
| Setup fee | `$5,500` |
| Monthly fee | `$799/mo` |
| Implementation time | `2-3 weeks` |
| ROI expected | `Faster lead response, improved enrollment conversion, stronger retention visibility, more predictable revenue management` |

**Includes**

- Everything in Growth
- Refined GHL branding setup
- Additional workflow tuning for edge cases
- Deeper dashboard configuration
- Partner / staff onboarding support
- Snapshot-ready structure for future replication
- 1 optimization review after go-live
- More structured handoff documentation

**Does not include**

- Full custom software development
- Opsly platform changes
- AI agent building
- Infrastructure management outside the agreed GHL scope

ICSO helps academies capture leads, automate follow-up, and gain visibility into their enrollment pipeline using GoHighLevel.

### Call to action

Book a discovery call to review your current flow and choose the best implementation path.

## Sales Script

### Short opener

`We help academies turn inbound leads into enrolled students using a simple system in GoHighLevel. The goal is to reduce missed leads, improve trial booking, and make enrollment more predictable.`

### Value framing

`Most academies lose money because leads arrive from different channels and follow-up is inconsistent. We fix the workflow first, then we measure the conversion.`

### Package positioning

`If you only need lead capture and reminders, Starter is enough. If you want the full enrollment system and dashboard visibility, Growth is the best fit. If you want a more complete rollout with onboarding support and stronger structure, Pro is the option.`

### Close

`If this looks aligned, the next step is a short discovery call so we can confirm scope and recommend the right package.`

## Discovery Call Script

### 1. Context

`Tell me how leads currently come in and what usually happens after a parent or student shows interest.`

### 2. Pain

`Where do you lose the most time or the most leads today?`

### 3. Trial process

`How do trial classes get booked, reminded, and followed up today?`

### 4. Conversion

`What percentage of trial classes become enrollments, and what usually blocks the close?`

### 5. Visibility

`What do you wish you could see in one dashboard every week?`

### 6. Scope

`Do you want something light and fast, or a more complete system with reporting and tighter follow-up?`

### 7. Close

`Based on what you shared, I would recommend Starter, Growth, or Pro. I can send the proposal after this call.`
