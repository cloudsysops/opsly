## Orden de la demo (20 min)

### 1. Captación (3 min)

1. Abrir landing en móvil y desktop.
2. Mostrar formulario: acudiente, modalidad, barrio, edad.
3. Enviar interesado de prueba **solo si quieren ver el flujo en vivo** (borrar después en admin).
4. Mensaje clave: *"Cada formulario entra al dashboard — no hay que copiar a Excel ni a otra herramienta."*

### 2. Dashboard admin (5 min)

1. Login → KPIs + **Interesados recientes**.
2. Abrir WhatsApp desde la fila (wa.me manual — canal Business = fase 2).
3. Cambiar estado: nuevo → contactado.
4. Sección **Seguimientos**: crear uno y marcar completado.
5. Mensaje clave: *"Todo el embudo en un solo panel."*

### 3. Integraciones (2 min)

Mostrar tarjeta **Conexiones activas** (tras deploy #779):

- **Twenty** — CRM sync
- **n8n** — automatizaciones

No prometer GHL ni WACRM si están apagados.

### 4. Clases de prueba (3 min)

Admin → **Clases de prueba**:

- Agendar clase para un interesado.
- Estados: agendada → confirmada → completada.

### 5. Operación real post-reunión (5 min conversación)

| Tarea | Cómo |
|-------|------|
| Cargar estudiantes reales | Admin o import Supabase (equipo Opsly apoya primera carga) |
| Profesores | `/teacher/login` — cuentas reales, no `.demo@peskids.co` |
| Familias | Fase 2 — portal `/familias` opcional en demo |
| WhatsApp masivo | Manual hoy; WACRM cuando activen sidecar |
