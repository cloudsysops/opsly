# Peskids design pack (referencia)

Prototipo Napkin exportado a JSX/HTML. **No se ejecuta en CI** — sirve para comparar con `apps/peskids/`.

| Archivo | Uso |
|---------|-----|
| `src/landing.jsx` | Landing V1 editorial + V2 bold |
| `src/app-flow.jsx`, `src/design-canvas.jsx` | Portal familias (base de `portal-showcase.tsx`) |
| `src/admin.jsx` | Panel admin (referencia) |
| `src/brand.jsx`, `src/logo.jsx` | Marca y lockup |
| `Peskids.html` | Vista previa navegable de todas las pantallas |

Assets binarios grandes (`uploads/*.png`) no están en git; usar el ZIP original del equipo de diseño.
