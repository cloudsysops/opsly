# Reports MOC

Snapshots, informes de sesión, evidencias E2E y análisis puntuales.

## Qué va aquí

- Resultados históricos o de una ejecución concreta.
- Evidencia de validación.
- Análisis que no es fuente canónica.

## Qué no va aquí

- Planificación viva; usar `../01-development/`.
- Auditorías formales; usar `../audits/`.
