# Development MOC

Roadmap vivo, planificación, sprints, estado de producto y handoffs de desarrollo.

## Qué va aquí

- `ROADMAP.md`, `VISION.md`, sprint plans e informes de semana.
- Planes de producto o implementación que siguen activos.
- Handoffs y guías para continuar trabajo de desarrollo.

## Qué no va aquí

- Arquitectura estable; usar `../00-architecture/`.
- Runbooks operativos; usar `../runbooks/`.
- Reportes históricos cerrados; usar `../history/` o `../reports/`.

## Documentos clave

- `ROADMAP.md`
- `VISION.md`
- `IMPLEMENTATION-IA-LAYER.md`
- `SEMANA-6-PLAN.md`
- `SPRINT-TRACKER.md`
