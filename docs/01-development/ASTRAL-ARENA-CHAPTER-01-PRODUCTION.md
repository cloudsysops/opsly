# Astral Arena — Chapter 1 Production Pack

Machine-readable source:

`config/games/astral-arena-chapter-01-production.json`

Generate the executable work list:

```bash
npm run content:astral:chapter1:plan
npm run content:astral:chapter1:plan:json
```

The pack currently expands four episodes into **24 governed deliverables**:

- 4 episode masters;
- 8 Shorts/story cuts;
- 4 thumbnails;
- 4 trailer beats;
- 4 Steam screenshot candidates.

All outputs flow through canonical Content OS v2 and Moon approval.

## Important

A Steam screenshot candidate is not automatically a Steam-approved screenshot.
It becomes store material only after:
- real gameplay source is verified;
- the depicted feature exists in the reviewed build;
- Moon approves;
- Steam store review constraints are satisfied.

The production pack is a queue contract, not a publisher.
