# Astral Games Lab — Incubation Protocol v1

## Loop

```text
DISCOVER -> OBSERVE -> IDEATE -> PROTOTYPE -> PLAYTEST -> MEASURE -> GRADUATE
```

Every experiment records hypothesis, mechanic genome, original-expression statement, controls, target device, success metric, license/provenance, playtest summary and graduation decision.

## Graduation gate

1. Original expression confirmed.
2. License/provenance gate passes.
3. Build reproducible.
4. Target controls work.
5. Playtest evidence exists.
6. No child PII is required.
7. Maintainer explicitly approves graduation.

Games Lab is R&D. It does not own publishing, Creator OS, or game canon.
