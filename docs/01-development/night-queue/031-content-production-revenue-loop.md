# Content Production — Revenue Loop

## Mission

Turn existing Content Studio/Content Engine capabilities into a measurable content-production loop that supports Opsly sales and customer acquisition.

## Reuse

- existing content-studio/content-engine packages;
- existing rendering pipeline;
- PC Gamer compute worker;
- approval-based publishing;
- current analytics/metrics where available.

## First outputs

1. Opsly engineering/agent-ops technical content;
2. Peskids case-study content using approved/non-sensitive data;
3. Health Tourism demo content using synthetic data;
4. founder portfolio/Career OS technical proof content.

## Workflow

`idea -> brief -> script -> assets -> render -> human approval -> publish -> metrics -> learning`

No autonomous publishing in MVP.

## Metrics

- assets produced/week;
- approved/published;
- views/impressions;
- qualified inbound;
- demo requests;
- content-to-lead conversion;
- production cost;
- GPU/runtime cost.
