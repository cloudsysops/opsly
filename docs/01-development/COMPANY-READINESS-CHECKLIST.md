# Company Readiness Checklist

This document is operational guidance, not legal, tax or accounting advice.

## Ready to bill

- [ ] Opsly product ownership is confirmed under the company entity.
- [ ] Business bank account is separate from personal accounts.
- [ ] Bookkeeping system is active.
- [ ] Terms of Service baseline exists.
- [ ] Privacy Policy baseline exists.
- [ ] Customer agreement / order form path exists.
- [ ] DPA template exists where processing role requires one.
- [ ] IP assignment / contractor / agent-output ownership language reviewed.
- [ ] Production approval boundaries documented.
- [ ] Support contact and response expectations documented.

## Ready for enterprise sales

### Security / trust

- [ ] Access-control inventory.
- [ ] Node identity and credential revocation.
- [ ] Agent action audit log.
- [ ] Encryption-in-transit baseline.
- [ ] Encryption-at-rest responsibilities documented.
- [ ] Security incident runbook.
- [ ] Dependency/security scanning current.

### Reliability

- [ ] Backup schedule documented.
- [ ] Restore drill completed and timestamped.
- [ ] RTO defined.
- [ ] RPO defined.
- [ ] Single-VPS failure plan documented.
- [ ] SLA/SLO by plan defined.

### Privacy / data

- [ ] Data inventory per tenant.
- [ ] Data-flow diagram for sensitive verticals.
- [ ] Data retention/deletion policy.
- [ ] Subprocessor/vendor list.
- [ ] DPA applicability reviewed.
- [ ] Regulatory applicability reviewed based on actual data flow, not vertical label.

### Commercial

- [ ] Flagship offer selected.
- [ ] Pricing and packaging published internally.
- [ ] Unit economics by tenant visible.
- [ ] Gross margin target defined.
- [ ] Case study with measurable outcome.
- [ ] Sales qualification criteria.
- [ ] Standard proposal/order form.

## Evidence rule

A checkbox is complete only when a durable artifact exists:

- GitHub doc/ADR/PR;
- executed test/report;
- signed external document;
- accounting record;
- customer-approved artifact.

Do not mark items complete based on verbal intent alone.
