# Full Startup Maturity Audit

## Objective

Audit Opsly/IntCloudSysOps as if preparing for:
1. first repeatable customers;
2. a senior architecture review;
3. a small technical due-diligence process;
4. migration from founder-operated infrastructure to a small team.

## Domains

Score each 0-5 with evidence.

### Product
- clear ICP
- repeatable offer
- onboarding
- tenant portability
- customer success
- pricing
- demo readiness

### Platform
- architecture clarity
- control/data/compute separation
- queues/idempotency
- tenancy
- provider portability
- developer experience

### Reliability

- SLOs

- backups
- restore tests
- failure recovery
- capacity limits

### Security

- CI supply chain

### AI

### Engineering

## Output

For each domain:
- score;
- evidence;
- top 3 gaps;
- top 3 strengths;
- one 30-day outcome;
- one 90-day outcome.

Final:
- startup maturity score;
- top 10 risks;
- top 10 leverage opportunities;
- infrastructure purchase priorities;
- founder learning priorities;
- customer/revenue priorities.
