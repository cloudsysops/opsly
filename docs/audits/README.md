# Audits MOC

Auditorías técnicas, seguridad, performance, calidad y bases de cobertura.

## Qué va aquí

- Auditorías formales y análisis de riesgo.
- Baselines de seguridad/performance/cobertura.

## Qué no va aquí

- Evidencia temporal de un smoke; usar `../reports/`.
- Runbooks de corrección; usar `../runbooks/`.
